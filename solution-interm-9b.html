Third conditional

I can talk about imaginary events in the past.

Ngữ pháp: Câu điều kiện loại 3 (Third conditional)
1. Cấu trúc và cách dùng ▼
Công thức (Form):
  • If + S + had + Vpast participle, S + would/could/might + have + Vpast participle
  • If I had known about the party, I would have come.
  • If we hadn't been so tired, we would have watched the film.
Cách dùng (Use):
  • Dùng để nói về một tình huống không có thật trong quá khứ và kết quả tưởng tượng của nó.
  • Diễn tả sự hối tiếc hoặc chỉ trích về một sự việc đã xảy ra trong quá khứ.
  • I wish I had studied harder. (Tôi ước mình đã học chăm hơn.)
If you had told me, I would have helped you.
She could have won the race if she had trained more.
We might have missed the train if we had left later.
⚠️ Lưu ý quan trọng:
  • Trong mệnh đề if dùng quá khứ hoàn thành (had + V3/ed).
  • Trong mệnh đề chính dùng would/could/might + have + V3/ed.
  • Không dùng would have trong mệnh đề if.
2. So sánh với các loại câu điều kiện khác ▼
LoạiThời gianCấu trúcVí dụ
Loại 0 Luôn đúng If + S + Vhiện tại, S + Vhiện tại If you heat water, it boils.
Loại 1 Tương lai có thể xảy ra If + S + Vhiện tại, S + will + V If it rains, I will stay home.
Loại 2 Hiện tại không có thật If + S + Vquá khứ, S + would + V If I were rich, I would travel.
Loại 3 Quá khứ không có thật If + S + had + Vp.p, S + would have + Vp.p If I had known, I would have helped.
